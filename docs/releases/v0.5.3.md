## 安装

从本页 Assets 下载 `luyi0825-zcode-acp-0.5.3.tgz`，本地安装：

```bash
npm install -g ./luyi0825-zcode-acp-0.5.3.tgz
zcode-acp login      # 浏览器授权登录（一次性）
zcode-acp doctor     # 自检：Node / CLI 定位 / 登录态 / 模型列表
zcode-acp setup      # 自检 + 打印各客户端接入配置
```

`doctor --probe` 会实跑一轮 headless 对话做端到端验证。

## 新增

### Claude Code stream-json 兼容入口

新增 `src/claude.js`，让 Mutica 一类把 agent 按 Claude Code stream-json 协议驱动的宿主可以直接拉起 zcode-acp：

- `control_request` / `initialize` 握手做模型发现，上报每个模型实际支持的思考档位；
- `--effort` 按**模型同名档位**映射到 ZCode 的 `reasoningLevel`，不再硬编码 low/medium/high；模型不支持某档时回退到该模型默认档；
- 支持 `--resume` 续接与 interrupt 中断。

README 相应更新 Mutica 接入建议（推荐 claude protocol family）。

### ACP 图片输入

ACP 端声明 image 能力：PNG / JPEG / GIF / WebP 落临时文件后交由 zcode 的 `Read` 工具读取，回合结束清理临时目录；纯图片消息自动补提示文本。

### 斜杠命令

- 推送 `session/available_commands` 菜单；
- 输入 `/技能名` 自动改写为 `/skill 技能名`，避免与内置命令撞名；
- 模型与思考档位选项补充 `category=thought_level` 语义标记。

### 文档

- README 更新 Mutica 接入建议与思考级别说明。

## 修复

- **provider 配置**：修正内置 provider 配置的兜底路径推断，Desktop 重定向场景下模型列表不再为空。
- **macOS 独立运行**：修正 `<bundle>/Contents/Resources` 布局下的 CLI 定位，独立运行不再依赖 Desktop 进程。
- **runtime-env 路径校验**：在 normalize 之前检查路径段 `..`，修复穿越校验被 normalize 抹平的问题。
- **开关型配置**：不再把布尔型配置伪装成强度滑块，模型发现的选项类型与实际配置一致。

## 变更

- 项目内统一改称 `zcode-acp`（此前文档中混用 bridge）。
- 补充思考级别与权限模式（`plan` / `build` / `guarded` / `yolo`）说明。
- 安装方式改为 GitHub Releases 下载 tarball 后本地安装。
